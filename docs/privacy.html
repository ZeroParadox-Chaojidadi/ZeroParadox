Privacy

Privacy policy

Last updated: October 21, 2026

ZeroParadox is a local Windows application. It does not operate an account service, analytics service, or advertising service.

Data stored on the device

  • Launcher settings, instance definitions, and local logs.
  • Minecraft username and UUID associated with a local or Microsoft account.
  • Microsoft OAuth access and refresh tokens for Microsoft accounts.

This data is stored in the launcher's local data directory. Tokens are not sent to the ZeroParadox project or to any third-party server operated by the project.

Network requests

The launcher contacts the following services only as needed to install and run the game:

  • Microsoft identity, Xbox Live, and Minecraft Services endpoints for sign-in.
  • Mojang and Fabric endpoints for version metadata and game files.
  • Modrinth for content search and downloads.

These services have their own privacy policies. Microsoft passwords are entered only on Microsoft's login page; ZeroParadox never receives them.

Telemetry and analytics

ZeroParadox does not include telemetry, crash reporting, advertising, or third-party analytics. This project website is static and does not use cookies or tracking scripts.

Deleting data

Accounts can be removed from the launcher's account window. Removing the launcher's local data directory deletes all locally stored settings, accounts, tokens, and logs.

Contact

For privacy questions, open an issue in the project's GitHub repository.
